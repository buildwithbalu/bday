📁 Manual Memory Add

Add A New Memory

To keep this website completely free, add your photo or video to the project's assets folder, then add one entry to EDITABLE_CONTENT.

Put the file in src/assets/images/private/ and add it to the secretRoom.photos list.

Put the file in src/assets/videos/private/ and add it to the secretRoom.photos list with type: 'video'. 

            
                url: 'assets/images/private/my-memory.jpg',
                caption: 'A memory worth keeping ❤️',
                date: '10 Oct 2026',
                type: 'image',
               tag: 'Our Memory'

After adding the file and configuration, run npx ng build and redeploy.
